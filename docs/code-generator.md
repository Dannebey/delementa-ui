# Инструкция по использованию генератора

## Запуск генератора

Вы можете запустить генератор двумя способами:

### 1. Интерактивный режим

Выполните команду:
```bash
  npm run new
```

Затем выберите нужный генератор и введите имя (например, Button).

### 2. Немедленный запуск

Вы также можете передать параметры напрямую:
```bash
  npm run new component Button
```
Эта команда сразу сгенерирует компонент с именем Button.

### Доступные генераторы
```
• component – React-компонент (TS + SCSS + тесты + Storybook)
• hook – React-хук (TS)
• type – TypeScript тип
• util – Утилитная функция (TS)
```

### Результат генерации

При генерации компонента с именем Button будет создана директория:

```
src/components/Button
```

с файлами:
```
• Button.tsx
• Button.module.scss
• Button.stories.tsx
• Button.test.tsx
• index.ts
```
